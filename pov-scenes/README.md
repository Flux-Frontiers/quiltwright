# POV-Ray scenes

Original scenes, kept at their original syntax. Quiltwright ray-traces them
without editing a line — a wrapper scene `#include`s the file and appends one
camera per view, so anything here can be turned into a quilt as-is. See
[docs/povray.md](../docs/povray.md).

| Directory | What is in it |
|---|---|
| [`myinclude/`](myinclude/) | Shared includes: atom/bond primitives, bell-jar geometry, cameras, skies, rainbow. Every scene below reaches into this. |
| [`museum/`](museum/) | "Eric's Science Museum", 1995–99. Three cuts of the room plus its furniture, pictures and textures. |
| [`bell_jar/`](bell_jar/) | The bell-jar still lifes the museum's pedestals were built from — B-DNA and Z-DNA under glass, on a marble stand, over sea and sky. |
| [`porin/`](porin/) | Porin, the β-barrel membrane protein, as a ribbon cartoon over water under a rainbow. |

## museum/

`museum.pov` is the canonical cut and the one
[`scripts/render_museum_hologram.py`](../scripts/render_museum_hologram.py)
drives; [about-the-image.md](../docs/about-the-image.md) describes what is on
the walls.

| Scene | Notes |
|---|---|
| `museum.pov` | Canonical cut. The image in the README. |
| `museum_dark.pov` | Same room, interior lighting only. |
| `museum_970211.pov` | 1997 cut, kept for provenance. |
| `museum_new_990101.pov` | 1999 cut — the last one. Adds the healthcare floor logo, the DNA cartoon mobile, the Risedronate exhibit and a tree outside the window. Pulls its wall pictures from `picframe_new.pov`, which reads them out of `pics/`. |

`pics/` holds the framed pictures at the path `picframe_new.pov` asks for
(`./pics/*.tga`). The five that both picture-frame files use also sit flat in
`museum/`, where the older `picframe.pov` expects them; the files are
byte-identical, so git stores each one once.

The standalone scenes are `museum*.pov`, `worldmap.pov` and `disc1.pov`. The
rest — `window.pov`, `picframe*.pov`, `display_base.pov` and `zdna.pov` — are
fragments meant to be `#include`d and carry no camera of their own.

## bell_jar/

| Scene | Notes |
|---|---|
| `bj.pov` | "DNA Under Glass" — B-DNA under the jar, sea and sky behind. |
| `bj_black.pov` | The same still life on black, for print. |
| `bdna.pov` | B-DNA alone on a checkerboard, no jar. |
| `yinyang.pov` | B-DNA and Z-DNA side by side under two jars. |
| `bdna/` | Variant of the still life plus the turntable animation (`bdna_anim.pov` + `bdna_anim.ini`). Its `bell_jar.inc`, `bna7_full.inc` and `bdna.pov` differ from the copies one level up; the rest are the same files. |

The `.inc` files are the molecules: `bna7_full.inc` (B-DNA, generated by
pdb2pov from `bna7_full.pdb`) and `zdna_bj.inc` / `zdna_full.inc` /
`bdna_bj.inc` (the same duplexes posed for the jar). `bna7_full.inc` is the one
that declares `ATM_SCL`, so it has to be included before any of the others —
which is why `zdna.pov`, which includes only `atoms_vdw.inc` and `atoms2.inc`,
stops on an undeclared `ATM_SCL` if you render it directly. It is a geometry
fragment with no camera, and was never a scene. `bna7_full.pov` does carry a
camera, but only declares the molecule without instantiating it, so it renders
an empty frame.

## porin/

`3porin.pov` is self-contained apart from `rainbow.inc`, and is the scene the
`.ini` is written for. `3porin2.pov` is a plain-background test cut that
`#include`s `3porin.inc`.

**`3porin.pov` carries no `#version` pragma**, so POV-Ray 3.5+ parses it as
modern source and stops on the first semicolon-less `#declare`. Pin the
language version instead of editing the file — see below.

## Rendering these directly

POV-Ray 3.7 (`sudo apt install povray`, `brew install povray`) needs the
include path pointed at `myinclude/` alongside its own:

```bash
cd pov-scenes/bell_jar
povray +Ibj.pov +Obj.png +W480 +H600 +FN +A0.3 -D \
       +L/usr/share/povray-3.7/include +L../myinclude
```

Most of these scenes declare `#version 3.0` themselves. `3porin.pov` does not,
and needs the language version pinned on the command line:

```bash
povray +I3porin.pov ... +MV3.1
```

`+MV3.1` is the non-destructive form of the `#version 3.1;` pragma described in
[pdb2pov.md](../docs/pdb2pov.md) — same effect, but the scene file stays as it
was written. Either way POV-Ray still prints `Possible Parse Error` warnings
for the 2.x-syntax `#declare`s in `myinclude/`; they are warnings, and the
render is correct.

The same argument reaches the quilt renderer through `extra_args`:

```python
from quiltwright import QUILT_PRESETS, PovCamera, render_pov_quilt

quilt = render_pov_quilt(
    "pov-scenes/porin/3porin.pov",
    QUILT_PRESETS["portrait"],
    PovCamera(location=(0, 0, -1100), look_at=(0, 0, 0), fov=53.13),
    include_paths=["pov-scenes/myinclude"],
    extra_args=["+MV3.1"],
)
```
